# Ejercicios – Fundamentos

1. Crea una página que reciba un nombre por `GET` y salude de forma personalizada.
2. Agrega una condición: si no hay nombre, muestra un formulario para capturarlo.
3. Crea un formulario `POST` con validación básica (nombre y email obligatorios).
4. Imprime los datos recibidos en una tabla HTML.
